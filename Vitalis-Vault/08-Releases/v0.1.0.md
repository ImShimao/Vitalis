# Vitalis 0.1.0 : changelog

## Ce qui est dans cette version

- Shell WinUI 3 : menu de dix pages, raccourcis Ctrl+1 à Ctrl+0, thème suivant Windows (clair, sombre, ou choix).
- Inventaire matériel via WMI (processeur, carte mère, BIOS, mémoire, cartes graphiques, écrans, réseau, audio).
- Santé des disques et espace libre (statuts Sain, Attention, Critique). SMART après relance administrateur.
- Mises à jour Windows (lecture seule) et logiciels winget (lecture seule, `winget upgrade`).
- Tableau de bord : score sur 100 (formule : ADR-008), cartes, analyse avec progression et annulation.
- Rapport HTML et PDF (Edge), sans données personnelles.
- Pilotes : règle des deux ans, liens fabricants vérifiés (4 sur 11).
- Démarrage : liste et désactivation réversible avec confirmation.
- Performances : benchmarks CPU, RAM, disque ; GPU non mesuré ; historique et comparaison.
- Paramètres : thème, mode diagnostic, journal Serilog local.

## Non inclus dans 0.1.0

- Santé live (températures) : étape 10, en attente de décision (pilote noyau, licence, Vanguard).
- Analyse planifiée et notifications Windows : étape 11 partielle.
- Installeur, signature de code, mise à jour automatique : étape 12 (certificat et choix à faire).
- Mises à jour winget par API COM : remplacées par la commande (ADR-007).

## Connus, à corriger

- **Publication `dotnet publish` incomplète** : les fichiers XAML compilés (`.xbf`) et `Vitalis.App.pri` ne sont pas copiés ; l'application plante au démarrage. Contournement : distribuer le dossier de build (`bin\x64\Release\...\win-x64`). À corriger.
- **Pilotes génériques Microsoft** comptés comme « anciens » (214 sur 256 sur la machine de développement).
- **Relance administrateur** : non testée jusqu'au bout depuis le bouton.
- **Windows 10** : non testé (aucune machine).
- **Format texte de winget** : vérifié avec winget 1.29.380 seulement.
- **Rendu PDF** : non vérifié visuellement.

## Prérequis

- Windows 10 22H2 ou Windows 11, x64.
- Windows App Runtime 1.8 installé (sauf version autonome, non retenue à ce stade).
- Microsoft Edge (export PDF).
- winget (mises à jour de logiciels).
